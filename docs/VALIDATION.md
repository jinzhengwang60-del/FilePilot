# FilePilot 0.1.0 验证记录

首次公开前在 Windows 11 x64 / Python 3.13.9 / PySide6 6.9.2 / pytest 8.4.2 上重新验证。验证日期：2026-10-14。

## 自动测试

完整测试：**58 passed, 1 skipped**，耗时 3.41 秒。跳过的是创建真实符号链接：本机 Windows 账户缺少对应权限。真实 Windows 联接点循环、目标父目录被联接点替换、硬链接、重名竞争和 NTFS 附加数据流保护均通过测试。

测试数据仅在项目专用临时目录创建；未整理或删除个人文件。原始报告包含本机绝对路径，留在本地，不进入公开仓库。

覆盖范围包括：

- 只读扫描、扩展名分类和无副作用预览。
- 相同内容与同大小不同内容的 SHA-256 检查，空文件处理。
- 系统与敏感目录、隐藏项、缓存、链接循环和访问拒绝。
- 明确确认、保留至少一份副本、不覆盖同名目标、变化文件阻止操作。
- 同盘移动与撤销、内容与修改时间及附加数据流保持。
- 取消、部分失败、跨进程锁和中断后记录核对。
- Qt 桌面扫描、表格勾选与筛选、预览确认、移动、历史及撤销。

GitHub Actions 对每次推送及拉取请求执行 Windows / Python 3.11、3.13 测试。线上结果以 [Actions 记录](https://github.com/jinzhengwang60-del/FilePilot/actions/workflows/test.yml) 为准。

## 桌面与打包验证

已在真实 Qt 界面上使用 15 个生成的演示文件，检测出 3 组重复；实际移动 3 个演示文件、撤销 3 个，并核对原路径、内容及重复组。README 中的截图来自实际程序的只读扫描，使用相对演示目录。

本机 PyInstaller 6.22.3 目录式构建已通过原生 Windows 启动检查。检查清除了 Python 与 Qt 搜索路径，将 PATH 限定为 Windows 系统目录，确认程序独立启动、展示三个页面并创建专用 QA 数据库。ZIP 解压后的程序也通过相同检查。

可执行程序和本机 QA 产物不纳入 Git 源码历史；在 Windows 上使用 README 的打包命令自行构建。

## 尚未验证的范围

- 尚未在全新虚拟机、其他 Windows 版本、不同安全软件或数十万文件规模下测试。
- 本机未能执行真实符号链接创建测试；CI 是否执行该项取决于运行账户权限。
- 首版仅支持同盘移动；隔离区保留完整副本，不能直接释放空间。
- 撤销保留空输出目录。文件系统操作不是整个批次的单一事务。
- 路径校验不能完全防御恶意进程的同时替换；应在自己控制的普通本地文件夹使用。
